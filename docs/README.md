# docs

| 폴더 | 누가 쓰나 | 내용 |

| `lessons/` | Claude | **단계별 교재.** 과제+코드 전문+해설+질문+삽질+팁+면접 문답을 한 파일에. 복기용 |
| `handbook/` | Claude | 서문+교재 전체+부록을 묶은 PDF. `build.sh`로 재생성. 그림은 `img/` |

| `troubleshooting/` | Claude | 사용자가 막힌 문제 하나당 파일 하나. 증상 / 오해 / 원인 / 해결 |
| `retro/` | Claude | 단계 종료 시 대화 기반 회고 |
