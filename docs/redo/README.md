# 재구현 (redo)

2026-10-01 시작. 2·3단계가 "틀 받아서 채우기"였으므로, 1단계 끝 시점 코드(`0df3072`)를 `kanban-redo/`에 복사해 **2단계 → 3단계를 스펙만 보고 다시 구현**한다.

## 규칙
1. `kanban/`(원본)과 `docs/lessons/`(교재)를 보지 않는다. `docs/stages/02-*.md`, `03-*.md` 스펙만 연다.
2. 15분 넘게 막히면 교재의 **해당 절만** 보고, 뭘 봤는지 채팅에 적는다. Claude는 힌트를 주지 않는다.
3. 파일 하나 끝낼 때마다 "뭘 하고 왜 이렇게 했는지" 두 줄을 채팅에 쓴다.
4. 완성 후 "리뷰해줘". Claude가 원본과 나란히 비교해 차이를 짚는다.
5. 순서: 삭제 → 추가 → 수정 → (리뷰) → 리듀서만 도입 → Context → (리뷰).

cd kanban-redo && pnpm dev   # 포트 5174
