# 부록 A — 핵심 개념 한눈에

| 개념 | 한 줄 | 어디서 |
|------|------|--------|
| 옵셔널 `?` | "비어 있을 수 있음"이 아니라 "없을 수 있음(undefined)". 컬렉션은 `[]`로 필수. | 1장 |
| 도메인 타입 vs Props 타입 | 데이터 모양(`type.ts`) vs 컴포넌트 입력 계약(컴포넌트 파일 안). props엔 콜백도 들어간다. | 1장 |
| 매개변수 구조분해 | `{ card }: CardProps`의 중괄호 안 이름은 타입에 실제 있는 키. | 1장 |
| key | map이 반환하는 요소에, 안정적인 id로. props가 아님. index면 "자리"에 붙어 상태가 엉뚱한 항목에 남음. | 1장 |
| `&&` 조건부 렌더링 | 왼쪽이 falsy면 왼쪽 값 반환. `0`은 그려진다. | 1장 |
| flex 방향 | 자식이 아니라 부모 컨테이너에. | 1장 |
| 단방향 데이터 흐름 | 데이터는 props로 아래로, 사건은 콜백으로 위로. 상태는 한 곳. | 2장 |
| 함수는 값 | `onX={f}`는 같은 함수에 이름표 추가. 화살표로 감싸면 새 함수. | 2장 |
| 포장지 패턴 | `onClick={() => f(id)}`(인자 넣기), `onX={(a) => g(myId, a)}`(내 정보 끼우기). | 2장 |
| 콜백 시그니처 원칙 | 말단은 모르는 정보 요구 안 받음 / id는 map 도는 곳에서 / 중간층은 통과. | 2장 |
| 불변 업데이트 3종 | 삭제 `filter`, 추가 `[...arr, x]`, 수정 `map` + `{ ...x, k }`. React는 참조(`Object.is`)로 변경 감지. | 2장 |
| 제어 컴포넌트 | `value` + `onChange` 세트. React 상태가 단일 진실 원천. | 2장 |
| 이벤트 버블링 | 자식 이벤트가 부모로 전파. 부모 onClick + 자식 input = 의심. | 2장 |
| setState는 줄 세우기 | 값 형태는 클로저의 낡은 값으로 지금 계산, 함수형은 React가 최신 상태로 나중에 계산. 의존하면 함수형. | 2장 |
| 리듀서 | `(state, action) => newState` 순수 함수. React 없이 호출 가능. | 3장 |
| useReducer | useState인데 새 값 대신 액션을 넣고 리듀서가 계산. | 3장 |
| discriminated union + never | `type`으로 좁히기. `default`의 `never`로 case 누락을 컴파일 타임에. | 3장 |
| 리듀서 순수성 | 같은 입력 같은 출력. 랜덤/시간/fetch는 dispatch 쪽에서. StrictMode 2회 호출 안전. | 3장 |
| Context | props 안 거치는 배달 통로(의존성 주입). 상태 관리 아님. Provider 서브트리 범위. 전역 아님. | 3장 |
| Context 분리 | 자주 바뀌는 값(board)과 불변(dispatch)을 나눠 리렌더 범위 축소. | 3장 |
| Fast Refresh | 컴포넌트만 export하는 파일에서만. 훅/Context 객체는 파일 분리. | 3장 |

# 부록 C — 작업 습관 (팁 모음)
- **TS 에러 읽는 법:** `missing`, `not assignable` 앞뒤의 타입 이름·속성 이름을 찾아 타입 정의와 대조.
- **타입 먼저, 데이터 나중.** `const x: Board = ...`로 붙이면 빠진 필드를 에디터가 알려준다.
- **작은 것부터.** Card → Column → Board.
- **한 기능을 끝까지.** 삭제 하나를 App→Card까지 완주하면 나머지는 반복.
- **잘 모르는 쪽부터 시작.** 체인을 알면 말단(Card)부터, 말단을 알면 App부터.
- **TS 에러 = 할 일 목록.** props를 지우거나 추가하면 빨간 줄이 다음 파일을 가리킨다.
- **조건문은 소리 내 읽기.** `!`가 들어간 조건은 "참일 때 뭘 하나"를 말로.
- **리팩터는 한 번에 하나.** 리듀서 도입 → 확인 → Context 도입.
- **리듀서 디버깅은 Node에서.** React 없이 호출해 출력을 본다.
- **포맷팅은 도구에.** `pnpm format`.
